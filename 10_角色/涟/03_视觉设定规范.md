# 涟（Lian）· 视觉设定 v1.3 草案

## 一、设计摘要

涟以纯白犬兽人[[黑羽]]的身体轮廓为基础，融合海水色共生特征、半液态身体结构与研究所监控设备。整体呈清爽少年感，气质柔软亲和，深海异种感集中在内耳、虹膜、左眼下水痕、尾尖、背部软鳍与黏液表现。

- **外观年龄**：约18岁
- **身高**：约170cm
- **体型**：偏瘦、有运动感，肩略窄、腰线收敛、重心偏低
- **主体毛色**：奶白至浅米
- **头部轮廓**：中短口鼻、适量脸颊与下巴绒毛、自然层叠碎发

### 六项核心识别

1. **海水色内耳**：奶白外耳搭配完整浅海水蓝绿内耳。日常双耳直立；放松、害羞或与亲近者互动时左耳轻微下垂。
2. **涟漪双环虹膜**：偏大的圆眼、圆形瞳孔、两圈平滑水波色环。
3. **左眼下水痕印记**：左眼下方排列两枚短小、略带斜向的水滴状色块，边缘带有轻微擦伤感，同时呈现泪痕与水痕意象。
4. **随机区块挑染**：头发中分布少量青蓝色区块，位置可在刘海、顶部碎发与两侧毛发之间变化，整体保持清晰区块感。
5. **功能监控项圈**：深炭色尼龙带、银灰金属扣件、固定环与小型矩形监控模块。
6. **半液态渐变尾尖**：蓬松中长尾由奶白渐变至海水蓝绿，尾尖呈湿软垂坠质感。

### 次级元素

- 鼻子为暖黑色，眉毛为深棕色，肉垫为淡粉色。
- 裸露背部可见成对叶状／潮痕状鳍纹。
- 左耳耳饰作为场景化造型元素。
- 日常服装以宽松T恤、卫衣、连帽衫、休闲裤、牛仔裤和休闲鞋为主。
- 研究所与实验课造型可搭配衬衫、白大褂或宽松外套。
- 雨天造型使用带耳洞的透明帽兜雨衣。

## 二、状态系统

### 显形层级

| 层级           | 场景           | 形态表现                                      |
| ------------ | ------------ | ----------------------------------------- |
| **Lv0 常态**   | 日常、学生生活      | 背部软鳍收拢为贴合身体的鳍纹，体表保持蓬松毛发质感                 |
| **Lv1 微显形**  | 轻度兴奋、进入浅水    | 鳍纹颜色加深并出现微光，尾尖湿软感增强                       |
| **Lv2 中显形**  | 强烈情绪、战斗准备    | 鳍纹抬起并展开为15–60°肉质软鳍，毛发略微贴服，体表黏液增加          |
| **Lv3 全显形**  | 全力行动、深水、极端情绪 | 软鳍展开至约90°，边缘强荧光，身体呈半液态，移动留下短暂发光痕迹         |
| **Lv4 液态形态** | 隐蔽、重伤、极限状态   | 身体化为中间略厚、边缘极薄的奶白色水洼，内耳与虹膜颜色浮于表面，并保留小型尾尖轮廓 |

### 情绪显色

完整内耳、涟漪虹膜、左眼下水痕印记与尾尖同步呈现情绪色。Lv2以上状态将同色反馈延伸至软鳍边缘与移动痕迹。挑染、肉垫、鼻子、眉毛和项圈保持基础配色。

| 情绪状态 | 特征色 | 黏液表现 |
|---|---|---|
| 平静／放松 | 海水蓝绿 `#4A9B8E` | 清透水膜 |
| 专注／好奇 | 青 `#3C7A8C` | 清透水膜 |
| 紧张／担忧 | 青紫 `#6B5B95` | 水膜与少量圆润水滴 |
| 激动／兴奋／生气 | 洋红 `#E85D9A` | 明显水膜与果冻高光 |
| 失控／极端 | 红 `#C7446E` | 大量水膜、果冻高光与荧光痕迹 |

内耳使用对应情绪色的浅色版本，虹膜维持双环结构，左眼下印记保持两枚斜向水滴轮廓，尾尖维持奶白至情绪色的渐变。显色可以在常态发生，软鳍从Lv2开始展开。

## 四、标准画法

1. 头部使用中短口鼻、适量脸毛和自然层叠碎发。
2. 内耳完整覆盖浅海水色，左耳在放松与害羞状态轻微下垂。
3. 虹膜使用圆形瞳孔与两圈平滑同心色环。
4. 左眼下方使用两枚短小斜向水滴色块，呈现水痕与浅擦伤质感。
5. 挑染使用少量随机区块，分布在刘海、顶部碎发与两侧毛发之间。
6. 鼻子使用暖黑色，眉毛使用深棕色，肉垫使用淡粉色。
7. 项圈呈现尼龙带、金属扣件与矩形监控模块三个结构层次。
8. 尾尖呈奶白至特征色渐变，并带有湿软半液态质感。
9. 背部鳍纹在Lv2抬起为一对肉质、半透明、柔软薄膜鳍。
10. 体态保持肩部略窄、腰线收敛与偏低重心。
11. 黏液使用清透水膜、果冻高光与少量圆润水滴表现。

## 五、交付与简化

### 小尺寸画法

- 虹膜保留两圈清晰色环与圆形瞳孔。
- 左眼下印记简化为两枚清晰的水滴状色点。
- 挑染保留少量独立色块。
- 尾尖使用奶白与特征色两段色块。
- 项圈保留尼龙带轮廓、金属扣件与矩形监控模块。
- 内耳使用单一浅海水蓝绿色块。
- 肉垫统一使用淡粉色。
