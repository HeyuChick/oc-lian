# 涟（Lian）· 视觉设定 v1.4 工作稿

> [!important] 版本范围
> 本轮已认可头部与全身三视图的整体方向，并明确选择「青蓝内耳内染＋青蓝头发色缘」。本文件将其整理为工作母版，不把生成图的每一个细节都视为最终确认。未展示的形态不删除，冲突项集中列在第五节。本轮参考图尚未收入仓库，不创建不存在的图片链接。

## 一、设计摘要

涟以白色犬兽人[[黑羽]]为身体基础，采用日系卡通造型、概括毛束和清楚线稿。奶白身体保持完整统一，异种感主要由浅乳白耳组织内的青蓝色核，以及白色头毛边缘少量青蓝色缘表达。整体安静、清爽、柔软，有少年感，但不是幼儿比例，也不是人类脸加兽耳。

- 外观年龄约18岁，身高约170cm；偏瘦、有运动感，肩略窄、腰线收敛。
- 中短犬科口鼻、暖黑鼻、分组脸颊毛与下巴毛；自然层叠、略不对称的主刘海和两侧碎发。
- 上眼睑、眉毛与耳姿共同表达情绪；不将单张图的半眯眼固定成性格。
- 毛领与颈胸毛比较蓬松，腹部和四肢长段简洁；前臂、腰侧、小腿附近以成组毛束调节轮廓。
- 中长蓬松犬尾与适度兽爪；不新增品种设定，不因参考图偏狼感而将种族改成狼或狐。

### 核心识别：同色系、不同分色结构

**耳朵内染。** 外耳与耳缘保持奶白，青蓝色核位于浅乳白组织内部，并与外轮廓留出浅色间隔。少量圆润、不规则形状表现颜色从内部透出，不再把整个内耳均匀铺满浅海水色。

**头发色缘。** 毛束内部保持白色，仅少数主毛束的一侧边缘与发梢带青蓝。色带宽窄有变化，可中断、收窄、消失；不逐缕描边，不形成全头连续彩色轮廓，不沿用随机整块挑染。

**大白底与局部呼应。** 头部是主要辨识区；肩部、腰侧及尾毛可用少量同源色缘呼应。胸腹保持安静，尾部末段可以比身体其他部位更集中，但不铺成均匀的大片蓝色。

**固定深色项圈。** 深炭尼龙带、银灰金属扣件和小型矩形监控模块保留为功能性配饰。其职责是解释监控身份，不增加额外挂饰来弥补造型。

### 沿用与保留

浅青蓝／海水蓝绿眼睛、圆形瞳孔和涟漪双环虹膜暂沿用旧设，等待更明确的眼部特写。水痕默认仍为左眼下两枚短小斜向印记；双颊版本仅作候选。鼻子为暖黑，眉毛为深棕，肉垫暂为淡粉，爪部保持圆钝。

## 二、状态系统

### 显形层级

本轮只更新常态外观。以下共生机制沿用既有设定，具体显形外观仍需新图验证，不能用常态三视图推断已取消。

| 层级 | 场景 | 形态表现 |
|---|---|---|
| Lv0 常态 | 日常、学生生活 | 毛发蓬松，背部软鳍收拢为贴合身体的鳍纹；鳍纹与背毛的关系待补图 |
| Lv1 微显形 | 轻度兴奋、进入浅水 | 鳍纹颜色加深并出现微光，尾尖湿软感增强 |
| Lv2 中显形 | 强烈情绪、战斗准备 | 鳍纹抬起为15–60°肉质软鳍，毛发略贴服、黏液增加 |
| Lv3 全显形 | 全力行动、深水、极端情绪 | 软鳍展开至约90°，边缘强荧光，身体半液态，留下短暂发光痕迹 |
| Lv4 液态形态 | 隐蔽、重伤、极限状态 | 奶白水洼中间略厚、边缘极薄，保留内耳、虹膜与小型尾尖轮廓 |

### 情绪显色

本轮改变的是颜色分布方式，不另立新的情绪规则或能量数值。

| 情绪状态 | 沿用的色彩方向 | 表现 |
|---|---|---|
| 平静／放松 | 海水蓝绿 | 色块柔和、清楚；不要求发光 |
| 专注／好奇 | 青 | 仍保留稳定的浅色外层与白毛 |
| 紧张／担忧 | 青紫 | 可配合少量水膜与圆润水滴 |
| 激动／兴奋／生气 | 洋红 | 既有动态区域显色更明显 |
| 失控／极端 | 红 | 可与全显形的水膜、荧光痕迹配合 |

内耳仅让色核响应，外耳和浅色边界保持稳定；虹膜、水痕和尾尖沿用既有联动，Lv2以上延伸至软鳍边缘与移动痕迹。头发及身体毛束色缘暂不新增情绪联动，维持固定青蓝色，等待专项确认。肉垫、鼻子、眉毛与项圈不参与显色。

颜色、透明度与发光分别控制：耳朵可以呈现内染但不发光，头发可以有青蓝色缘但仍是不透明毛发。显色可以发生在Lv0，软鳍从Lv2开始展开。

## 三、材质与配色

### 材质层次

- 毛发：奶白、不透明、蓬松，使用轮廓和大毛束表现；遇水后才明显贴服。
- 内耳共生组织：浅乳白外层包着有色核心，使用少量深浅色块与高光暗示柔软通透，不表现裸露内脏。
- 尾尖与软鳍：常态尾毛保持蓬松；遇水、显形时加强湿软、半液态和薄膜感。
- 项圈：深色哑光尼龙、银灰金属，矩形模块大小克制，不与脸部争抢焦点。

### 色彩职责

| 色彩 | 职责 |
|---|---|
| 奶白至浅米 | 主体与主要留白，维持白色犬兽人印象 |
| 浅灰 | 结构阴影，不误读为新增灰色毛斑 |
| 浅青蓝／蓝绿 | 内耳色核、头毛和局部尾毛色缘；同色系但不同面积与深浅 |
| 暖黑／深炭 | 鼻子、线条和功能项圈等少量固定深色 |
| 银灰 | 项圈金属部件 |
| 淡粉 | 沿用的肉垫色；新图深灰方案另行确认 |

新参考图中的色卡尚未经过色值确认。以下旧工作色保留为过渡参考，不宣称与新图逐像素一致：奶白 #FAF7F0、浅米 #F0EBE3、暖灰 #E7E1D7、海水蓝绿 #4A9B8E、青蓝 #4A90A4、浅海水蓝绿 #8FC8BE、荧光青绿 #7DD3C0、淡粉 #FFB8C6、暖黑 #1F2421、深棕 #4A342B、深炭 #263238、硬件青蓝 #3C5A78、银灰 #B0BEC5。既有情绪工作色为青 #3C7A8C、青紫 #6B5B95、洋红 #E85D9A、红 #C7446E。

## 四、标准画法

1. 先画完整犬兽人结构和有节奏的毛束，再加分色；不把细毛、透明效果当作造型替代品。
2. 耳芯有色、外侧留白；青蓝不均匀铺满整个内耳。
3. 头发选少数主毛束做色缘，不做随机块状挑染，不逐缕彩描。
4. 保留中短犬科口鼻与清楚鼻口关系；不缩成人类鼻嘴或拉成写实长狼吻。
5. 眼睛保持可表达性；双环与圆瞳仍按既有规范，不能从概念图推断新的瞳孔类型。
6. 胸毛、脸颊毛和四肢毛簇以组为单位，躯干、关节与毛量应能跨视角对应。
7. 体型偏瘦、有轻度肌肉结构，不固定为厚胸宽肩或过量腹肌刻画。
8. 尾根与大部分尾毛保持白色，末段用色缘呼应；液态版另画，不用同一张图同时硬塞全部形态。
9. 以平涂和少量分块阴影为主；半厚涂只能补充柔和光感，不改成写实动物毛皮或全身塑料果冻。
10. 结构三视图可不画日常服装，但保留项圈；不因此取消日常穿衣设定。

## 五、交付与简化

### 小尺寸画法

首先保留立耳、主刘海、犬科口鼻、青蓝耳芯、少数发缘与深色项圈。主体依然读作白色小狗。尾部保留白毛与少量青蓝末端，不要求逐根表达色缘；眼睛的双环可简化，但不可擅自改成竖瞳。左眼下双滴维持清楚形状。

### 必须单独复核的细节

| 项目 | 图稿与既有设定的差异 | 本次处理 |
|---|---|---|
| 肉垫与爪色 | 旧设淡粉肉垫；新三视图有深灰肉垫与爪尖 | 不自动改色，保留深灰候选 |
| 面部水痕 | 旧设仅左侧双滴；新头图与正面图有双颊标记 | 默认仍为左侧，双颊方案待确认 |
| 眼睛 | 概念图不能清楚确认圆瞳与双环细节 | 沿用旧微结构，补眼部特写 |
| 腿足 | 概念图不足以精确定义足跟、趾行／跖行与爪趾数量 | 不写死结构，补无毛或简化骨架检查图 |
| 毛束色缘 | 头、肩、腰与尾部的彩边跨视角并非严格对齐 | 当前固定语法，不锁定每一小块的位置 |
| 特殊形态 | 常态图未清楚展示软鳍、液态尾尖与液态身体 | 保留原机制，后续补独立形态页 |
| 显色联动 | 对话明确选择了青蓝配色和两种分色，但未定头发动态规则 | 不新增联动，另行比较 |

参考图是造型与分色探索，不是可直接建模的精确结构蓝图。最终三视图应检查同一高度基准、主刘海方向、印记左右、尾根位置、关节与配色位置；先解决这些，再增加细节。
