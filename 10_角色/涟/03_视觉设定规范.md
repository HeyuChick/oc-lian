# 涟（Lian）· 视觉设定规范 v1.4

> [!important] 版本范围
> 本版已正式锁定常态（Lv0）头部与全身三视图规范（参考图收录于[[涟-AI概念画廊]]方案 08、09）：日系奶白犬兽人、内耳青蓝色核（外耳与耳背全白）、双颊对称水痕、全身仅保留「头发＋尾巴末段」青蓝色缘（躯干、四肢与常态背部全白）、五指手爪与趾行四趾兽足、淡粉肉垫、浅色圆钝爪，以及全显色部位情绪同步联动。

## 一、设计摘要

涟以白色犬兽人[[黑羽]]为身体基础，采用日系卡通造型、概括毛束和清楚线稿。奶白身体保持完整统一，异种感主要由浅乳白耳组织内的青蓝色核、双颊对称水痕，以及「头发 + 尾巴末段」的少量青蓝色缘表达。整体安静、清爽、柔软，有少年感，但不是幼儿比例，也不是人类脸加兽耳。

- 外观年龄约18岁，身高约170cm；偏瘦、有运动感，肩略窄、腰线收敛。
- 中短犬科口鼻、暖黑鼻、分组脸颊毛与下巴毛；自然层叠、略不对称的主刘海和两侧碎发。
- 上眼睑、眉毛与耳姿共同表达情绪；浅青蓝／海水蓝绿圆瞳，带涟漪感双环虹膜。
- 毛领与颈胸毛比较蓬松，腹部和四肢长段简洁；前臂、腰侧、小腿附近以成组毛束调节轮廓。
- **手爪为五指结构**，**脚部为趾行（digitigrade）兽爪、四趾脚爪**；手掌与足底**肉垫统一为淡粉色（`#FFB8C6`）**，爪尖为浅米／象牙色圆钝爪。

### 核心识别：同色系、不同分色结构

1. **耳朵内染（外耳与耳背全白）**：外耳、耳缘及耳背保持纯白／奶白（耳背严禁画青斑）。青蓝色核位于内耳浅乳白组织内部，并与外轮廓留出浅色过渡间隔。
2. **仅保留「头发 + 尾巴末段」色缘（身体与背部全白）**：
   - 头发内部保持不透明白色，仅少数主毛束的一侧边缘与发梢带青蓝，可自然收窄或中断。
   - 尾巴大部分保持奶白，仅在中后段／末段沿少数毛束边缘与毛尖带青蓝。
   - **躯干、肩部、手臂、腰侧、腿部与常态背部完全保持纯白／奶白色**，不画零散碎色。
3. **双颊对称水痕**：左右眼下（双颊）各两枚对称分布的短小斜向水滴印记。
4. **固定深色监控项圈**：深炭尼龙带、银灰金属扣件和正面小型矩形监控模块。

## 二、状态系统

### 显形层级

| 层级 | 场景 | 形态表现 |
|---|---|---|
| Lv0 常态 | 日常、学生生活 | 毛发蓬松，背部保持纯白（软鳍完全隐没于背毛下），仅头部与尾末带青蓝色块／色缘 |
| Lv1 微显形 | 轻度兴奋、进入浅水 | 背部浮现浅青蓝潮痕状鳍纹并带微光，尾尖湿软感增强 |
| Lv2 中显形 | 强烈情绪、战斗准备 | 背部抬起15–60°肉质半透明软鳍，毛发略贴服、黏液增加 |
| Lv3 全显形 | 全力行动、深水、极端情绪 | 软鳍展开至约90°，边缘强荧光，身体半液态，留下短暂发光痕迹 |
| Lv4 液态形态 | 隐蔽、重伤、极限状态 | 奶白水洼中间略厚、边缘极薄，保留内耳、虹膜与小型尾尖轮廓 |

### 情绪显色（全部位同步联动）

**只要是显色的部位，均随情绪同步变色。**

| 情绪状态 | 显色部位同步色彩方向 | 表现 |
|---|---|---|
| 平静／放松 | 海水蓝绿／青蓝 | 色块柔和、清楚；不要求发光 |
| 专注／好奇 | 青 | 仍保留稳定的浅色外层与白毛 |
| 紧张／担忧 | 青紫 | 可配合少量水膜、左耳微垂、尾巴绕腿 |
| 激动／兴奋／生气 | 洋红 | 动态区域显色更明显，尾尖湿软轻摆 |
| 失控／极端 | 红 | 配合全显形的荧光软鳍、水膜与发光痕迹 |

- **同步显色部位**：内耳色核、虹膜、双颊对称水痕、头发色缘、尾巴末段色缘，以及显形状态下的背部软鳍与移动痕迹，全部在同一情绪档位下保持同色系同步变化。
- **固定不显色部位**：外耳与耳背白毛、主体奶白毛发、淡粉肉垫、浅色爪尖、暖黑鼻子、深棕眉毛与深炭监控项圈保持原色不变。

## 四、标准画法（Do & Don't）

1. **必须双颊对称水痕**：左右眼下各两枚斜向水滴印记，不画成单侧。
2. **耳背与躯干必须纯白**：青色只出现在内耳色核、眼瞳、双颊水痕、少数头发边缘与尾巴末段；耳背、肩、腰、小腿、常态背部均不涂青蓝。
3. **五指手＋趾行四趾足＋淡粉肉垫**：手部五指、足部趾行四趾，肉垫统一为淡粉色，爪尖为浅色圆钝爪（严禁画成深灰／黑色肉垫或利爪）。
4. **少年感犬兽人比例**：中短犬科口鼻，18岁偏瘦有运动感的修长少年体态，不画成厚胸宽肩的健美公模狼人。
5. **矩形监控项圈**：颈部佩戴带银灰金属件与正面矩形监控模块的深炭尼龙项圈，不画成普通皮带针扣。
